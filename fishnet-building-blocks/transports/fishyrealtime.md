# FishyRealtime (Photon)

{% hint style="danger" icon="dollar-sign" %}
While the FishyRealtime Transport itslef is free and under the MIT license, Exit Games' Photon Realtime is subject to their own service charges and license.
{% endhint %}

## Description

FishyRealtime is a transport that allows the [Photon Realtime](https://www.photonengine.com/Realtime) service from the company **Exit Games** to work with FishNet!

## Component settings

* **Photon APP ID:** The app id of the Photon Realtime product.
* **App Version:** The version of the product (game), only clients with the same version can connect to each other.

#### Default room options

* **Max Players:** Default max players.
* **Is Visible:** Whether Room is Visible to Public Room List.
* **Is Open:** Whether the room is public or private.
* **Connection Protocol:** Connection Type.
* **Region:** The Region the Server is hosted on.
