# FishNet EOS Native (Epic Online Services)

## Description

FishNet EOS Native allows you to utilize [Epic's Online Services](https://onlineservices.epicgames.com/), such as matchmaking and relay, as the base of your FishNet connection.\
\
Unlike [FishyEOS](fishyeos-epic-online-services.md), this transport uses the raw EOS C# SDK directly—no PlayEveryWare plugin required.
